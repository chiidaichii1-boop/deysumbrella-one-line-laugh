## What it does

`main.py` (Python standard library only) writes a single original funny
one-liner to `entry.txt` in the output directory taken from the
`MAKEFUN_OUTPUT_DIR` environment variable (falling back to `/output`).
The line is a short joke about a dog's verdict on its owner's cooking —
one read, one turn, one laugh.
